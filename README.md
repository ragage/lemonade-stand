# lemonade-stand

A tiny practice project for a pretend lemonade stand. It lists drinks and prices and adds up an order.

See the \[menu](menu.md). 

**The repo uses Python's ignore file.** The `.gitignore` is GitHub's Python template (the same file `gh repo create … --gitignore Python` adds). It stops Python's cache folder (`__pycache__/`) from ending up in a commit.
